# Source Code Plagiarism Detection Using Token Streams

## Project Description
This project is a Python-based desktop application that detects similarity between two Python source code files using token streams.

## Features
- Select two Python files.
- Extract tokens from source code.
- Ignore comments and unnecessary whitespace.
- Compare token sequences.
- Calculate similarity percentage.
- Display similarity level (High, Moderate, Low).

## Technologies Used
- Python
- Tkinter
- Tokenize
- Difflib

## How to Run
1. Install Python.
2. Download the project.
3. Open the project folder in VS Code.
4. Run:

```bash
python plagiarism_detector.py
```
